# SIFRA Official Website

The official product website for **SIFRA** — an autonomous local AI research workspace and self-hosted search API.

Designed using an **Apple-inspired product design system** combined with **Linear's visual restraint** and **SIFRA's authentic technical architecture**.

---

## Key Features of the Redesigned Experience

1. **Light & Dark Surface Rhythm:**
   - Intentional alternation between warm ivory/paper surfaces and deep charcoal product showcases.
2. **2D System Storytelling:**
   - Interactive SIFRA Neural Research Hub topology diagram.
   - 4-pillar architectural inspector (Local Neural Engine, Docker SearXNG, SQLite FTS5 BM25, Hardware Intelligence).
   - 5-stage synthesis pipeline scrubber with live data input/output simulation.
3. **Authentic Product Showcase:**
   - High-resolution real application screenshots displayed inside a precision Apple Mac glass window frame with interactive tabs.
4. **Hardware Intelligence & Developer Workbench:**
   - Dynamic host RAM/VRAM model tier recommender (8GB Edge, 16GB Balanced, 32GB+ Workstation).
   - Interactive syntax viewer with tabbed cURL, Python, and Node.js fetch clients.
   - Functional interactive search & citation simulation widget.
5. **Security & Deployment Transparency:**
   - Clear architectural data boundary diagram distinguishing offline loopback operations from outbound SearXNG public search queries.
   - 3-command local Docker and Ollama setup guide with one-click copy actions.

---

## Tech Stack
- **Framework:** React 18 with TypeScript & Vite
- **Styling:** Tailwind CSS with custom Apple & Linear design tokens
- **Typography:** Plus Jakarta Sans & JetBrains Mono
- **Icons:** Lucide React
- **Bundle Footprint:** ~58 kB gzip (74 unused 3D dependencies pruned)

## Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run production build & preview
npm run build
npm run preview
```
